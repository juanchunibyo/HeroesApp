# Heroes App

Aplicacion web para explorar y administrar heroes, construida con React, TypeScript y Vite.

## Stack

- React 19
- TypeScript
- Vite
- React Router
- Tailwind CSS
- shadcn/ui

## Requisitos

- Node.js 20 o superior
- npm

## Instalacion

1. Clona el repositorio:

   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd 05-heroes-app
   ```

2. Instala las dependencias:

   ```bash
   npm install
   ```

3. Crea un archivo `.env` si el proyecto necesita variables de entorno.

## Desarrollo

Inicia el servidor local:

```bash
npm run dev
```
